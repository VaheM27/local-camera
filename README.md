# local-camera

Камера MacBook → Safari на iPhone по локальному Wi-Fi через WebRTC. Видео не уходит в интернет.

## Запуск

```bash
npm install
npm start
```

1. На Mac откройте `https://localhost:3000/` → «Включить камеру» (при желании отметьте «со звуком»).
2. На телефоне (в той же Wi-Fi сети) отсканируйте QR-код на странице вещания или откройте адрес `https://<IP-Mac>:3000/watch` (он выводится в консоли и на странице). `localhost` на телефоне не работает — это адрес самого телефона.
3. Safari предупредит о самоподписанном сертификате: «Показать детали» → «посетить этот веб-сайт». HTTPS нужен, иначе камера недоступна.
4. Если есть звук, на iPhone нажмите «Включить звук» (iOS не разрешает автозвук).

Порт меняется через `PORT=4000 npm start`. Сертификат создаётся автоматически в `certs/` и пересоздаётся при смене IP.

Если не соединяется: проверьте, что обе устройства в одной сети, что в Wi-Fi роутера не включена «изоляция клиентов» и что брандмауэр macOS пускает Node.

## Совместимость

- Вещать можно из любого браузера на Mac/ПК (Safari, Chrome, Firefox, Edge) — страница `https://localhost:3000/`.
- Смотреть можно с любого телефона и браузера (iPhone Safari/Chrome, Android Chrome/Firefox/Samsung Internet) — страница `/watch`.
- Основной режим — WebRTC (со звуком). Если за 8 секунд он не соединился (например, телефон не разрешает mDNS-адреса), страница сама переключается в запасной режим: кадры JPEG через WebSocket, без звука.

## Во весь экран и зум на телефоне

- **Зум:** щипок двумя пальцами, перетаскивание, двойной тап (×1 ↔ ×2.5), кнопки «+»/«−». Это цифровой зум: встроенная камера MacBook аппаратного зума не поддерживает. Если подключена камера с зумом (например, внешняя USB), на странице вещания появится ползунок «Зум камеры».
- **Во весь экран:** кнопка ⛶ работает на Android и iPad. На iPhone Safari полноэкранный режим для страниц недоступен — нажмите «Поделиться» → «На экран Домой» и открывайте значок: страница запустится без адресной строки.
