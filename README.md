# local-camera

Камера MacBook → Safari на iPhone по локальному Wi-Fi через WebRTC. Видео не уходит в интернет.

## Запуск

```bash
npm install
npm start
```

1. На Mac откройте `https://localhost:3000/` → «Включить камеру» (при желании отметьте «со звуком»).
2. На телефоне (в той же Wi-Fi сети) отсканируйте QR-код на странице вещания или откройте адрес `https://<IP-Mac>:3000/watch` (он выводится в консоли и на странице). `localhost` на телефоне не работает — это адрес самого телефона.
3. Safari предупредит о самоподписанном сертификате: «Показать детали» → «посетить этот веб-сайт». HTTPS нужен, иначе камера недоступна.
4. Если есть звук, на iPhone нажмите «Включить звук» (iOS не разрешает автозвук).

Порт меняется через `PORT=4000 npm start`. Сертификат создаётся автоматически в `certs/` и пересоздаётся при смене IP.

Если не соединяется: проверьте, что обе устройства в одной сети, что в Wi-Fi роутера не включена «изоляция клиентов» и что брандмауэр macOS пускает Node.

## Совместимость

- Вещать можно из любого браузера на Mac/ПК (Safari, Chrome, Firefox, Edge) — страница `https://localhost:3000/`.
- Смотреть можно с любого телефона и браузера (iPhone Safari/Chrome, Android Chrome/Firefox/Samsung Internet) — страница `/watch`.
- Основной режим — WebRTC (со звуком). Если за 8 секунд он не соединился (например, телефон не разрешает mDNS-адреса), страница сама переключается в запасной режим: кадры JPEG через WebSocket, без звука.

## Во весь экран и зум на телефоне

- **Зум:** щипок двумя пальцами, перетаскивание, двойной тап (×1 ↔ ×2.5), кнопки «+»/«−». Это цифровой зум: встроенная камера MacBook аппаратного зума не поддерживает. Если подключена камера с зумом (например, внешняя USB), на странице вещания появится ползунок «Зум камеры».
- **Во весь экран:** кнопка ⛶ работает на Android и iPad. На iPhone Safari полноэкранный режим для страниц недоступен — нажмите «Поделиться» → «На экран Домой» и открывайте значок: страница запустится без адресной строки.
- **Громкость:** на странице телефона ползунок 0–200% (выше 100% — усиление) и кнопка выключения звука. Регулировка работает через Web Audio, поэтому действует и на iPhone, где Safari не даёт менять громкость видео. Физические кнопки громкости телефона тоже работают. Звук включается нажатием (требование браузеров) и недоступен в запасном режиме с кадрами JPEG.

## PIN-доступ

Страница `/watch` защищена PIN-кодом: без него сервер не покажет видео. PIN выводится в консоли и на странице вещания, а ссылка и QR-код уже содержат его (`/watch?pin=…`), поэтому при сканировании вводить ничего не нужно. Если открыть `/watch` без PIN, телефон попросит ввести его и запомнит. После 5 неверных попыток соединение закрывается.

- PIN создаётся при первом запуске и хранится в `certs/pin.txt`.
- Свой PIN: `PIN=1234 npm start` (4–8 цифр).
- Без PIN: `PIN=off npm start`.
- Вещать (страница `/`) можно только с самого Mac — с другого устройства сервер это не пропустит.

## Режим «заполнить экран» и иконка

- Кнопка ⤢ на странице телефона переключает «вписать целиком» и «заполнить экран» (края обрезаются, полос нет). Выбор запоминается.
- У приложения есть иконка: при «На экран Домой» на телефоне появится значок камеры вместо скриншота.

## Показ экрана Mac

На странице вещания выберите «🖥 Экран Mac» вместо камеры. Браузер предложит выбрать экран или окно. Источник можно менять на лету, не прерывая вещания. При первом использовании macOS попросит дать браузеру право «Запись экрана» (Системные настройки → Конфиденциальность и безопасность). Галочка «со звуком» добавляет микрофон Mac.

## Телефон → Mac (микрофон и камера)

На странице телефона есть кнопки «🎙 Говорить» и «📹 Моя камера». Звук и видео с телефона появляются на странице вещания в блоке «С телефона», получается рация или видеоняня в обе стороны. Работает только в основном режиме (WebRTC), не в запасном. Если включить микрофон на iPhone, iOS может сделать звук с Mac тише — это особенность iOS.

## Запуск двойным кликом и автозапуск (macOS)

- `start.command` — двойной клик: ставит зависимости при первом запуске, запускает сервер и открывает страницу вещания. Если macOS ругается на файл из интернета: правый клик → «Открыть».
- `install-autostart.command` — сервер запускается сам при входе в систему и перезапускается при сбое (лог: `~/Library/Logs/local-camera.log`). Страницу вещания нужно открыть и нажать «Начать вещание» — доступ к камере браузер даёт только по нажатию.
- `uninstall-autostart.command` — отключает автозапуск.

Если файлы не запускаются: `chmod +x *.command`.

## Постоянный адрес

Кроме IP на странице вещания показан адрес вида `https://<имя-Mac>.local:3000/watch?pin=…`. macOS сама объявляет это имя в локальной сети, поэтому ссылка не ломается при смене IP (например, после перезагрузки роутера) — её можно сохранить в закладки или на экран «Домой». Имя меняется в «Системные настройки → Основные → Общий доступ → Имя локального хоста». Другое имя: `HOST_NAME=camera.local npm start` (тогда нужно, чтобы оно разрешалось в сети). QR-код использует IP, потому что `.local` понимают не все телефоны (часть Android — нет).

## Приложение для macOS (установка как обычной программы)

Те же возможности, но отдельной программой: окно, значок в Dock и в строке меню, без Терминала и Node.js.

**Где взять.** В репозитории на GitHub: вкладка *Actions* → «Build macOS app» → последний запуск → *Artifacts* → `Local-Camera-mac`. Внутри `.dmg` для вашего Mac: `arm64` — Apple Silicon (M1/M2/M3/M4), `x64` — Intel. Новую сборку можно запустить кнопкой *Run workflow*; по тегу `v1.0.0` файлы появляются в *Releases*.

**Установка.** Откройте `.dmg` и перетащите *Local Camera* в «Программы».

**Первый запуск.** Приложение не подписано платным сертификатом Apple, поэтому macOS может сказать, что оно «повреждено» или от неизвестного разработчика. Это нормально:
- правый клик по приложению → «Открыть» → «Открыть»; или
- в Терминале один раз: `xattr -cr "/Applications/Local Camera.app"`.

Затем разрешите камеру и микрофон (при показе экрана — ещё «Запись экрана» в Системных настройках → Конфиденциальность и безопасность).

**Как работает.**
- Окно показывает страницу вещания. Если закрыть окно, приложение остаётся в строке меню и продолжает вещать; клик по значку в Dock или в строке меню возвращает окно. Полностью выйти: меню значка → «Выйти» или `⌘Q`.
- Меню значка: PIN, «Скопировать ссылку для телефона», «Запускать при входе в систему», «Начинать вещание автоматически» (камера включится сама, окно при входе в систему не показывается).
- Сертификат, PIN и настройки хранятся в `~/Library/Application Support/local-camera/`.

**Собрать самому** (на Mac): `npm install && npm run dist` — файлы появятся в `dist/`. Запуск без сборки: `npm run app`.
